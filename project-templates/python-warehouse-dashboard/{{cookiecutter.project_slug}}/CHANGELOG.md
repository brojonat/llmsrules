## [Unreleased]

### Added
- Generated from the `python-warehouse-dashboard` template: synthetic
  ticket feed (`generate`), DuckDB build of Parquet read models with a
  content-hash skip and a shrink guard (`build`), a per-session Datastar
  dashboard with a dataset builder and d3 Rocket components, an LLM
  assistant with sandboxed SQL, text search, charts and feedback, an eval
  runner, `/admin` diagnostics, Prometheus `/metrics`, a load tester, and a
  stateless Kubernetes deployment with litestream for the app DB.
